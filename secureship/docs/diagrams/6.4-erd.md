# 6.4 Data Model (ERD)

> Regenerated in Week 5 against the actual SQLAlchemy models (`backend/models/`).

```mermaid
erDiagram
    CUSTOMER ||--o{ SHIPMENT : has
    SHIPMENT ||--o{ PACKAGE : contains
    CUSTOMER ||--o{ CHAT_SESSION : "linked post-verification"

    CUSTOMER {
        string id PK "uuid"
        string first_name
        string last_name
        string phone_number "E.164 format"
        string address
    }

    SHIPMENT {
        string id PK "uuid"
        string customer_id FK
        string tracking_number UK
        enum status "label_created | in_transit | out_for_delivery | delivered | exception"
        string carrier
        string origin
        string destination
        date estimated_delivery
        timestamptz last_update "auto-updated"
    }

    PACKAGE {
        string id PK "uuid"
        string shipment_id FK
        string description
        decimal weight_kg "Numeric(8,2)"
        decimal declared_value "Numeric(10,2)"
    }

    CHAT_SESSION {
        string id PK "uuid"
        string customer_id FK "nullable — set on verified"
        string pending_customer_id "nullable — set on identity match, before code entry"
        enum state "anonymous | collecting_identity | code_sent | awaiting_code | verified | escalated_to_human"
        timestamptz started_at "server default now()"
        timestamptz ended_at "nullable"
        jsonb transcript "array of message objects"
        string verification_code "VARCHAR(6) nullable"
        timestamptz code_expires_at "nullable — 10-min window"
        int code_attempts "default 0 — max 3 before lockout"
    }
```

**Transcript JSONB schema** — each element:
```json
{
  "role": "user | assistant",
  "content": "string",
  "timestamp": "ISO-8601",
  "tool_calls": [
    {
      "name": "tool_name",
      "arguments": {"key": "value"},
      "result": {"key": "value"}
    }
  ]
}
```

`verify_identity` arguments are always stored as `{"_redacted": true}` — name, address, and phone number are never persisted to the transcript.

**Admin identity** lives entirely in Auth0 — there is no `admin_users` table. The JWT payload (sub, email) is returned from `GET /admin/me` but never written to the database.
